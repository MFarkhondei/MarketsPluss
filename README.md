# ویجت بازار لحظه‌ای (ثروتمندی)

ویجت اندروید جدا از ترید پلاس برای نمایش:

در زیر درصد تغییر هر بازار، `RSI` بر پایه قیمت‌های روزانه ذخیره‌شده در جدول
`market_daily_prices` نمایش داده می‌شود. برای اولین محاسبه، حداقل ۱۵ قیمت معتبر لازم است.

| ردیف | نام | واحد |
|------|-----|------|
| 1 | دلار آمریکا | تومان |
| 2 | انس طلا | دلار |
| 3 | طلا ۱۸ عیار | تومان |
| 4 | طلای بدون حباب | تومان (تقریبی) |
| 5 | سکه امامی | تومان |
| 6 | صندوق گنج | تومان |
| 7 | بیت‌کوین | دلار |
| 8 | اتریوم | دلار |
| 9 | انس نقره | دلار |
| 10 | انس مس | دلار |
| 11 | S&P 500 | — |
| 12 | Nasdaq | — |

| 14 | سهم موج | تومان |

## منبع داده

- دلار آمریکا، بیت‌کوین، اتریوم: **رمزینکس (Ramzinex)** — `exchange/api/v1.0/exchange/pairs` با `pair_id` به‌ترتیب ۱۱، ۱۲ و ۱۳
- انس طلا، انس نقره، انس مس، S&P 500، Nasdaq: **یاهو فایننس (Yahoo Finance)** — `v8/finance/chart/{symbol}`
- طلای ۱۸ عیار و سکه امامی: **TGJU**
- شاخص بورس / دلار، سهم موج، صندوق گنج: **TSETMC**

شناسه‌های Entity ثروتمندی/TGJU در کد `PriceClient.kt` برای مرجع ثبت شده‌اند.

- طلای بدون حباب: `انس طلا × دلار آمریکا ÷ 41.45`
- شاخص بورس/دلار: `شاخص کل ÷ دلار تومان`

## ساخت

```bash
./gradlew assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### GitHub Actions

با هر push به `main`/`master`، یا دستی از تب **Actions** → **Build APK** → **Run workflow**، فایل APK به‌صورت artifact با نام **`marketpluss-apk`** ساخته می‌شود.

بعد از اتمام workflow: Actions → run مربوطه → Artifacts → دانلود `marketpluss-apk`.

## استفاده

1. نصب APK
2. افزودن ویجت «بازار لحظه‌ای» به صفحه اصلی
3. لمس ویجت → تنظیم فاصله بروزرسانی
4. دکمه 🔄 برای رفرش دستی
5. لمس هر کارت برای مشاهده نمودار روزانه همان بازار با انیمیشن نمایش؛ تاریخ‌ها شمسی هستند و با لمس هر نقطه مبلغ و تاریخ همان روز نشان داده می‌شود

تنظیمات پیش‌فرض ویجت: حالت باکسی و بروزرسانی خودکار هر ۱۵ دقیقه.

**سامسونگ:** باتری اپ را بدون محدودیت بگذارید.
