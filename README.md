## منبع داده

سایت `servatmandi.com` API عمومی ندارد و اسکرپ HTML ناپایدار است.
این ویجت قیمت‌ها را از **API زنده بازار ایران (TGJU)** می‌گیرد که همان نمادهای دیده‌بان ثروتمندی را پوشش می‌دهد.

شناسه‌های Entity ثروتمندی در کد `PriceClient.kt` برای مرجع ثبت شده‌اند.

- حباب طلای ۱۸: اختلاف قیمت بازار با ارزش جهانی تقریبی (ons × دلار × ۱۸/۲۴ / ۳۱.۱)
- شاخص بورس/دلار: `شاخص کل ÷ دلار تومان`

## ساخت

```bash
./gradlew assembleDebug
```

یا GitHub Actions → artifact `servatmandi-widget-apk`.

## استفاده

1. نصب APK
2. افزودن ویجت «بازار لحظه‌ای» به صفحه اصلی
3. لمس ویجت → تنظیم فاصله بروزرسانی
4. دکمه 🔄 برای رفرش دستی

**سامسونگ:** باتری اپ را بدون محدودیت بگذارید.
